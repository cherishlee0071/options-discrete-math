# BRK.B 美式看跌期权的行权时间

双击 `demo.html` 即可离线演示。先切到三步手算例，点第 2 步并选择股价 64 的节点，观察该节点的到达概率和提前行权决策。再前进到第 3 步，观察到期行权和到期无价值如何分开统计。切回 BRK.B 后，可以拖动步数或点击分布图检查 12 步价格树。

## 数据和参数

- `data/brkb_window.csv` 保留 2026-07-29 至 2026-10-22 的 61 个 BRK.B 收盘价，取自用户提供的 Nasdaq 日线 `D:\Users\hp\Investing\USmarket\BRK.B_price.csv`。估值日收盘价为 546.97 美元。
- 年化历史波动率为 12.9078%，计算方法是 60 个日对数收益的样本标准差乘以 √252。
- `data/treasury_202610.csv` 是美国财政部 2026 年 10 月的原始 CSV。模型仅用 10 月 22 日 `3 Mo` 列的 4.22%，并直接作为常数连续复利率的近似。 [美国财政部历史利率表](https://home.treasury.gov/resource-center/data-chart-center/interest-rates/TextView?type=daily_treasury_yield_curve&field_tdr_date_value_month=202610)
- 合约参数为行权价 550 美元、剩余 90 个日历日、12 个等长时间步、无股息。合约为课堂设定，未使用期权市场报价校准。模型期权价格以每股计。

## 核心算法

每个节点用 `(步数, 上涨次数)` 表示。无股息 CRR 树使用 `u = exp(σ√Δt)`、`d = 1/u` 和 `R = exp(rΔt)`。上涨概率 `p = (R-d)/(u-d)`，下跌概率为 `1-p`。 [CRR 原论文](https://bpb-us-w2.wpmucdn.com/u.osu.edu/dist/7/36891/files/2017/07/CRR79-1yy8av8.pdf)

1. 从到期日倒推。每个节点比较立即行权收益与下一层价值的折现期望。两者相等时选继续持有。
2. 根节点的到达概率为 1。继续持有的节点向两条边按风险中性概率分流，多条路径到达同一节点时累加。行权节点保留到达概率并停止分流。
3. 到期时，把剩余概率分成有正收益的到期行权和无价值到期。逐步行权概率使用根节点初始概率作分母。图中概率是在模型和该最优策略下的风险中性概率。

## 复现与核验

在本目录运行 `python -B build_demo.py`。仅用 Python 标准库，读取本地行情窗口和利率 CSV，重新生成 `demo.html` 与 `exercise_distribution.csv`。如需从原始 `BRK.B_price.csv` 重新提取同一估值窗口，可传入 `--stock-file`。

构建时核对每一步进入的概率等于停止和继续概率之和，核对三类最终结果合计为 1，并验证向前累计的折现行权收益等于向后递推的根节点价值。另枚举 8 条和 4,096 条完整路径，分别复核三步例和 BRK.B 的逐步分布。
